# Product content rules

Write as an experienced international fashion e-commerce brand. Natural, fluent English. No emojis. No exaggerated claims.

## Universal content (one set for all colours)

Every product gets ONE title, ONE short description, ONE long description, ONE meta description and ONE SEO title that work for every colour variant. Never mention a specific garment colour. (Colours that are part of the artwork, e.g. "purple and gold print", are fine.)

| Field | Length | Notes |
|---|---|---|
| Product title | 45–80 chars | Design + key style words + "Graphic T-Shirt" / "Typography T-Shirt" |
| Short description | 30–50 words | What it is, what makes it appealing |
| Long description | 100–160 words | 3 short paragraphs: intro + design detail + fit/uses/gift |
| Meta description | 140–160 chars | Primary keyword early, ends with who it is for |
| SEO title | 50–60 chars | `<Main keyword phrase> | <Short category> Tee` |
| Primary keyword | 1 | Most likely search phrase |
| Secondary keywords | 5–8 | Used as tags, comma separated |

## Accuracy

- Describe only what is visible in the images, plus the store's fixed product facts from the config.
- Never invent fabric, weight, certifications, origin or performance claims.
- Two-sided designs: say what is on the front and what is on the back.
- Brand / licensed names: do not use them in title or tags unless the user confirms a licence. Describe generically.

## Long description template

1. Hook sentence naming the product and the main design element.
2. Detailed description of the artwork: elements, lettering, colours, style.
3. Fit and uses: "The classic crew neck, short-sleeve cut ..." + occasions + who it is a good pick or gift for.
